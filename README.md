# DIA-lab5
Лабораторная 5 по курсу Разработка интернет-приложений (МГТУ Канев А.И.)

ПОСТАНОВКА ЗАДАЧИ

Разработать базовый интерфейс приложения на React для гостя, аналогичный двум страницам из лабораторной работы №1 для просмотра услуг. При этом на странице списка услуг должны быть необходимые фильтры (по дате, названию или цене). Использовать компоненты React-Bootstrap. Для карточек предусмотреть изображение по-умолчанию, если поле в услуге пустое. Содержимое карточек получать только из коллекции с mock-объектами без бэкенда. На странице списка услуг отображается иконка корзины.

В приложении должны быть навигационная панель navbar для списка базовых страниц, а также самописная навигационная цепочка breadcrumbs, где отображается путь от базовой страницы к текущей. В этой лабораторной никакого Redux, а Context вообще в курсе использовать нельзя.
